# 魔法画框 FrameShift

把双手变成一个取景框：框住画面，试试不同风格；双手捏合，切换下一种效果；满意后，保存当前画面。

这是一个打开网页就能体验的浏览器互动影像工具。摄像头、手势识别和画面处理默认都在浏览器本地完成，不需要注册账号，也不需要 API key。

## 先体验

- [在线体验](https://easonsitu.github.io/Gesture-change-face/)
- [无摄像头示例](https://easonsitu.github.io/Gesture-change-face/?demo)
- [项目仓库](https://github.com/EasonSitu/Gesture-change-face)

在线体验由 GitHub Pages 提供，打开后摄像头、手势识别和画面处理仍在浏览器本地完成。

本地运行时，在项目目录启动一个静态文件服务器：

```powershell
py -m http.server 8123
```

然后打开：

- 摄像头模式：<http://localhost:8123>
- 无摄像头示例：<http://localhost:8123/?demo>
- 捏合模拟示例：<http://localhost:8123/?demo&pinch>
- 预选人物效果：<http://localhost:8123/?character=werewolf>

## 怎么玩

1. 允许摄像头，把两只手放进画面，用食指做上方两个角、拇指做下方两个角，组成一个画框。
2. 直接点选效果，或两只手同时捏合，让画框里的画面切换到下一种风格。
3. 点击“3 秒后保存”，把手放回画框，倒计时结束后下载当前画面。

画框不要求是规整的长方形，也可以是倾斜或不规则的四边形。手指翻转、四条边发生交叉时，画面会按两个三角形区域显示。框内应用效果，框外保留原始画面。

没有摄像头也可以先从示例开始。示例模式会生成一个本地绘制的人物和固定手部轨迹，适合第一次了解玩法、演示或排查设备问题。

## 效果选择

当前共有 14 个效果，按体验目的分成三组：

| 分类 | 效果 | 适合做什么 |
| --- | --- | --- |
| 基础效果 | 像素化、模糊、反色、黑白、故障、漫画、线稿 | 快速观察画框、颜色和边缘变化 |
| 趣味面具 | 狼人、老虎、小狗、匿名 | 让人物在画框里换一个轻松的角色 |
| 面具变脸 | 京剧、傩戏、黄梅戏 | 用东方戏曲面具做更有主题感的变脸体验 |

人物和面具效果只在画框内显示，切换时会按需准备所需的模型和运行资源。第一次使用某个效果可能需要等待几秒，页面会显示当前进度；如果素材没有准备好，可以重新尝试或先选择其他效果。

## 让一次体验顺利完成

这个项目把“能运行”之外的使用过程也放进了页面：

- 先看示例：没有摄像头、没有合适光线时，用户仍然可以理解玩法。
- 看得懂的状态：首次启动、切换效果、摄像头权限和失败重试都有明确提示。
- 两种操作方式：手动点选始终可用；捏合切换可以整体关闭，也可以分别选择参与循环的效果分类。
- 不打断画面：加载人物效果时保留当前画面，准备完成后再切换，避免旧效果和新效果叠在一起。
- 适配不同场景：桌面宽屏将画面固定在左侧、功能区放在右侧；小屏幕自动改为上下排列，并提供全屏模式。
- 结果可带走：倒计时截图直接下载浏览器当前合成画面，不需要上传到服务器。

## 技术实现

项目保持为无构建步骤的静态网页，核心流程如下：

1. 使用 [MediaPipe Tasks Vision](https://github.com/google-ai-edge/mediapipe/tree/master/mediapipe/tasks/web) 的 Hand Landmarker 获取两只手的指尖位置。
2. 将左食指、右食指、右拇指、左拇指组成固定路径，计算倾斜、不规则和交叉四边形；交叉时使用 `evenodd` 填充规则。
3. 基础效果直接在 Canvas 2D 上处理，并把效果裁剪到手指框内。漫画效果通过颜色分层和边缘描线增强画面；线稿效果使用 OpenCV.js 的 Canny 边缘流程。
4. 人物效果复用 [Jeeliz FaceFilter](https://github.com/jeeliz/jeelizFaceFilter) 的脸部跟踪和示例结构，配合 Three.js 渲染人物模型。
5. 三种戏曲面具以本地 GLB 形式放在 `assets/meshy/`，选择时按需读取，不在运行时访问 Meshy。
6. 对异步加载增加取消、过期结果保护和失败回退，避免快速切换效果时旧资源覆盖当前选择。

## 隐私、权限与运行边界

- 摄像头画面只在当前浏览器中处理，项目没有上传摄像头画面的接口。
- 不需要登录、后端数据库或 API key。服务器只负责返回 HTML、JavaScript、CSS 和静态资源。
- 摄像头模式需要浏览器权限；在本地 `localhost` 中即可直接测试。
- MediaPipe、手部模型和部分运行库默认从公共 CDN 加载，因此首次打开需要网络连接。重型人物资源、面具模型和 OpenCV.js 会按需加载。
- 当前版本没有发布音效功能，交互反馈通过画面、提示、倒计时和按钮状态完成。
- 这不是云端 AI 换脸或视频上传产品；当前重点是浏览器端实时互动、可理解的操作流程和本地体验。

## 测试

几何、手势、效果注册、人物渲染和界面契约使用 Node 内置测试，不需要安装 npm 依赖：

```powershell
npm test
```

也可以单独检查入口脚本：

```powershell
node --check main.js
```
